# Task B

In this section you will see four scenarios. Each one describes a situation under investigation and lists several techniques. Your task is to choose the one technique that is appropriate for that case.

Each technique is presented the same way as in the previous section: the title, along with either the paper's keywords or a set of ontology tags. Some cases use keywords and some use ontology tags; you will not see the same scenario in both formats. Below each one, you can open an AI summary, the abstract, and the full paper if you want them.

Only one of the techniques is a good fit. The others are close but not suitable, so read the case carefully first, then compare the techniques against it.

You do not need to open the same amount for every technique — you may find that some can be ruled out quickly while others need a closer look. Decide when you have enough to choose.

There are four of these to work through. There is no time limit. **Once you move on to the next case, you will not be able to return to a previous one.**
